## Workflow

1. `00_baseline/`: data preparation and original baselines.
2. `01_sid_generation/`: RQ-VAE training, SID generation, and
   collision handling.
3. `02_recsys/`: GPT2Rec training/evaluation notebooks.
4. `03_analysis/`: final experiment analysis, tie-break comparisons,
   and report tables.

The upstream notebooks are folded into the same coursework tree:

- `00_baseline/data_prep_diff_emb_upstream.ipynb`
- `01_sid_generation/RQVAE_train_stage_upstream.ipynb`
- `01_sid_generation/RQVAE_AntiContrastive_train_upstream.ipynb`
