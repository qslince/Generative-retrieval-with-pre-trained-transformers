# Структура текста курсовой

## 1. Введение

Кратко описать задачу sequential recommendation и проблему представления item'ов.

## 2. Цель и задачи

Цель: изучить влияние различных способов генерации семантических идентификаторов item'ов на конечные метрики RecSys.

Задачи:

- реализовать несколько способов SID;
- посчитать внутренние SID-метрики;
- обучить одинаковую RecSys-модель на разных SID;
- изучить связь SID-метрик с `Recall@K` и `NDCG@K`.

## 3. Метод

Описать:

- PLUM-like pipeline;
- RQ-VAE;
- codebooks;
- SID как последовательность токенов;
- GPT2Rec decoder.

## 4. Варианты SID

Описать:

- count suffix;
- no suffix + popular fallback;
- popularity suffix;
- centroid suffix;
- semantic residual suffix.

## 5. Эксперименты

Зафиксировать:

- датасет;
- item embeddings;
- train/valid/test;
- RQ-VAE settings;
- GPT2Rec settings;
- evaluation protocol.

## 6. Результаты

Показать:

- таблицу SID-метрик;
- таблицу RecSys-метрик;
- сравнение вариантов 5-го кода;
- сравнение "5-й код" vs "без 5-го кода".

## 7. Анализ связи метрик

Показать:

- Spearman heatmap;
- scatter plots;
- обсуждение, какие SID-метрики являются лучшими прокси.

## 8. Выводы

Сфокусироваться на ответах:

- помогает ли уменьшение коллизий;
- нужен ли 5-й код;
- какой способ обработки коллизий лучше;
- какие SID-метрики стоит использовать без обучения RecSys.
